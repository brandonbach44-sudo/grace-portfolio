Learning Support Math​ ​ ​ ​

PA Standards

  • CC.2.2.HS.D.9 / CC.2.2.7.EE.A.1 (foundational skill per IEP goals): Evaluate algebraic expressions by
  • substituting given values for variables and applying order of operations.

Essential Questions

  • How do we evaluate an algebraic expression when variables are replaced with given values?
  • How does order of operations guide us in evaluating expressions accurately?

Objectives

  • Students will be able to order a set of numbers, including decimals and square roots, from largest to
  • smallest.
  • Students will be able to substitute given values for variables in an algebraic expression, using
  • parentheses around each substituted value.
  • Students will be able to apply order of operations to correctly evaluate an expression after
  • substitution.
  • Students will be able to evaluate expressions involving exponents, absolute value, and multiple
  • variables.

Classroom Environment & Routines

  • Visual schedule displayed at the start of class showing today's materials and sequence of activities,
  • including the lunch break
  • Warm-up completed in table groups with an 8-minute visible timer to build routine and
  • time-awareness
  • Clear verbal and visual cues signal transitions, especially around the lunch break
  • Consistent routine: warm-up → review → notes/guided practice → independent practice → lunch
  • → review → practice worksheet → choice activity → closure
  • Positive reinforcement for on-task effort during independent work and choice activity

Materials Needed

  • ​
  • Visual schedule (board/projector)
  • Warm-up number-ordering cards (decimals, square roots, etc.) — one set per table group
  • Visible timer
  • Evaluating Expressions guided notes (All Things Algebra)
  • Whiteboard/projector for modeling examples
  • Independent practice worksheet (additional evaluating expressions problems)
  • Choice activity: color-by-number order of operations worksheet OR mixed practice worksheet
  • (evaluating expressions, absolute value, ordering numbers, order of operations)
  • Pencils, calculators (per accommodations)

Vocabulary

  • Variable — a letter that represents an unknown or changing number
  • Substitution — replacing a variable with a given number
  • Evaluate — to find the value of an expression
  • Order of operations (PEMDAS) — the order in which operations must be performed
  • Exponent — review
  • Absolute value — review

  • What will you do to bring closure to the lesson? How will you summarize this
  • lesson and preview the lesson that will follow?

  • operations.
